<Aside type="caution" title="Unofficial and not fully tested">
This interface exists in a personal fork of WinUtil, not in the official project. It runs as the real program: in this release the window was driven on a Windows 11 virtual machine, including a real install and uninstall of two programs, and in the earlier release two real tweaks were applied and undone on a PC. Scripts, services, HKLM, the restore point and the Chocolatey path from end to end were not tried. Tweaks change your system. Create a restore point first. You use it at your own risk.
</Aside>

## What it is

An opt-in interface for the Tweaks tab (and a new window around every tab): a sidebar, search, filter chips, tweak cards, a "Before you apply" panel, an estimated impact and a visible progress. The tweak, install and update logic is upstream's and was not changed. The original interface remains the default build.

## Run

```powershell
irm https://github.com/realfulvio/winutil/releases/latest/download/winutil.ps1 | iex
```

To build it yourself: `git clone https://github.com/realfulvio/winutil.git`, then `.\Compile.ps1 -Interface Redesign -Run` in the folder. Build without `-Interface Redesign` (or use the official command) to get the original interface.

## How to read a tweak card

- **Recommended** means the tweak is in upstream's Standard preset.
- **Advanced** means it is in upstream's "CAUTION" category, or it is a risky change of its own (services, Widgets removal, turning BitLocker off).
- **Safe** means it is neither.
- Click a card to see what changes, the possible effects, whether it can be undone and any warning. Whether it can be undone is read from the tweak's own undo data.
- The impact counts services and registry values of the selected tweaks. Memory, disk space and a privacy score are not shown because the repository has no data for them.

## Programs and kits

The Programs tab has a search box, **kits**, category chips with counters, one card per program (icon, name, a short line, category or "Installed", a checkbox and a ⓘ button for the details on the right) and a floating bar with the selection, Install and the progress. The "⋯" menu holds Uninstall, Upgrade all, "Select installed programs" and the choice between WinGet and Chocolatey. Install, uninstall and upgrade are upstream's own code.

- **Kits**: Office, Development and Gaming come with WinUtil. "Create kit from selection" saves your own in `%APPDATA%\WinUtil\kits`; **Export** writes a `name.winutil-kit.json` file (a network folder works) and **Import kit** reads one. The file holds package IDs (WinGet, or Chocolatey when there is no WinGet one), not names; programs the catalog does not have are skipped and counted.
- **Command line** (redesigned build, `winutil.ps1` as a file): `-Kit "path\kit.winutil-kit.json"` shows what the kit holds; add `-Installa` to install it with no window. Exit code 0 is success, 1 a bad kit or an installation with problems, 2 `-Installa` without `-Kit`.
- **Icons**: the program's own icon from its official site (cached in `%LOCALAPPDATA%\WinUtil\icons`, shown offline from the cache), else a brand outline from Simple Icons (CC0), else a glyph of the category. See `docs/ICONS.md` in the repository.
- **Home** is the first page: four numbered choices that open Programs, Tweaks, Updates and Repair. The sidebar is grouped: Install, Optimize, Maintenance, Advanced.

## Other settings

Switches, buttons and the Multiplane Overlay list apply immediately, as upstream does. The DNS list is applied by the Apply button.

### Cos'è

Un'interfaccia opzionale per la scheda Ottimizzazioni (e una nuova finestra attorno a ogni scheda): barra laterale, ricerca, filtri, schede delle ottimizzazioni, pannello "Prima di applicare", impatto stimato e avanzamento visibile. La logica di ottimizzazioni, installazioni e aggiornamenti è quella di upstream e non è stata cambiata. L'interfaccia originale resta la build predefinita.

### Avvio

```powershell
irm https://github.com/realfulvio/winutil/releases/latest/download/winutil.ps1 | iex
```

Per compilarla da sé: `git clone https://github.com/realfulvio/winutil.git`, poi `.\Compile.ps1 -Interface Redesign -Run` nella cartella. Compila senza `-Interface Redesign` (oppure usa il comando ufficiale) per avere l'interfaccia originale.

### Come leggere una scheda

- **Consigliata** significa che l'ottimizzazione è nel preset Standard di upstream.
- **Avanzato** significa che è nella categoria "CAUTION" di upstream, oppure che è una modifica rischiosa di per sé (servizi, rimozione dei Widget, disattivare BitLocker).
- **Sicura** significa che non è nessuna delle due.
- Clicca una scheda per vedere cosa cambia, i possibili effetti, se si può annullare e l'eventuale avviso. Se si può annullare lo si legge dai dati di annullamento dell'ottimizzazione stessa.
- L'impatto conta i servizi e i valori di registro delle ottimizzazioni selezionate. Memoria, spazio su disco e punteggio privacy non sono mostrati perché il repository non ha dati per questi.

### Programmi e kit

La scheda Programmi ha un campo di ricerca, i **kit**, filtri per categoria con contatori, una scheda per programma (icona, nome, una riga breve, categoria o "Installato", una casella e un pulsante ⓘ per il dettaglio a destra) e una barra flottante con la selezione, Installa e l'avanzamento. Il menu "⋯" contiene Disinstalla, Aggiorna tutto, "Seleziona i programmi installati" e la scelta tra WinGet e Chocolatey. Installa, disinstalla e aggiorna sono il codice di upstream.

- **Kit**: Ufficio, Sviluppo e Gaming sono inclusi. "Crea kit dalla selezione" salva i tuoi in `%APPDATA%\WinUtil\kits`; **Esporta** scrive un file `nome.winutil-kit.json` (va bene una cartella di rete) e **Importa kit** ne legge uno. Il file contiene ID dei pacchetti (WinGet, o Chocolatey se non c'è quello WinGet), non nomi; i programmi che il catalogo non ha vengono saltati e contati.
- **Riga di comando** (build ridisegnata, `winutil.ps1` come file): `-Kit "percorso\kit.winutil-kit.json"` mostra cosa contiene il kit; con `-Installa` lo installa senza finestra. Codice di uscita 0 = riuscito, 1 = kit non valido o installazione con problemi, 2 = `-Installa` senza `-Kit`.
- **Icone**: l'icona del programma dal suo sito ufficiale (in cache in `%LOCALAPPDATA%\WinUtil\icons`, mostrata offline dalla cache), altrimenti un profilo di marchio di Simple Icons (CC0), altrimenti un glifo della categoria. Vedi `docs/ICONS.md` nel repository.
- **Home** è la prima pagina: quattro scelte numerate che aprono Programmi, Ottimizzazioni, Aggiornamenti e Riparazioni. La barra laterale è a gruppi: Installa, Ottimizza, Manutenzione, Avanzate.

### Altre impostazioni

Interruttori, pulsanti e l'elenco Multiplane Overlay si applicano subito, come in upstream. L'elenco DNS si applica con il pulsante Applica.
