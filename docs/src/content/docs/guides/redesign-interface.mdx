<Aside type="caution" title="Unofficial and not fully tested">
This interface exists in a personal fork of WinUtil, not in the official project. It runs as the real program (tabs, cards, filters, search and language were used on Windows 11), and two real tweaks were applied and undone with it, but scripts, services, HKLM and the restore point were not tried. Tweaks change your system. Create a restore point first. You use it at your own risk.
</Aside>

## What it is

An opt-in interface for the Tweaks tab (and a new window around every tab): a sidebar, search, filter chips, tweak cards, a "Before you apply" panel, an estimated impact and a visible progress. The tweak, install and update logic is upstream's and was not changed. The original interface remains the default build.

## Run

```powershell
irm https://github.com/realfulvio/winutil/releases/latest/download/winutil.ps1 | iex
```

To build it yourself: `git clone https://github.com/realfulvio/winutil.git`, then `.\Compile.ps1 -Interface Redesign -Run` in the folder. Build without `-Interface Redesign` (or use the official command) to get the original interface.

## How to read a tweak card

- **Recommended** means the tweak is in upstream's Standard preset.
- **Advanced** means it is in upstream's "CAUTION" category, or it is a risky change of its own (services, Widgets removal, turning BitLocker off).
- **Safe** means it is neither.
- Click a card to see what changes, the possible effects, whether it can be undone and any warning. Whether it can be undone is read from the tweak's own undo data.
- The impact counts services and registry values of the selected tweaks. Memory, disk space and a privacy score are not shown because the repository has no data for them.

## Other settings

Switches, buttons and the Multiplane Overlay list apply immediately, as upstream does. The DNS list is applied by the Apply button.

### Cos'è

Un'interfaccia opzionale per la scheda Ottimizzazioni (e una nuova finestra attorno a ogni scheda): barra laterale, ricerca, filtri, schede delle ottimizzazioni, pannello "Prima di applicare", impatto stimato e avanzamento visibile. La logica di ottimizzazioni, installazioni e aggiornamenti è quella di upstream e non è stata cambiata. L'interfaccia originale resta la build predefinita.

### Avvio

```powershell
irm https://github.com/realfulvio/winutil/releases/latest/download/winutil.ps1 | iex
```

Per compilarla da sé: `git clone https://github.com/realfulvio/winutil.git`, poi `.\Compile.ps1 -Interface Redesign -Run` nella cartella. Compila senza `-Interface Redesign` (oppure usa il comando ufficiale) per avere l'interfaccia originale.

### Come leggere una scheda

- **Consigliata** significa che l'ottimizzazione è nel preset Standard di upstream.
- **Avanzato** significa che è nella categoria "CAUTION" di upstream, oppure che è una modifica rischiosa di per sé (servizi, rimozione dei Widget, disattivare BitLocker).
- **Sicura** significa che non è nessuna delle due.
- Clicca una scheda per vedere cosa cambia, i possibili effetti, se si può annullare e l'eventuale avviso. Se si può annullare lo si legge dai dati di annullamento dell'ottimizzazione stessa.
- L'impatto conta i servizi e i valori di registro delle ottimizzazioni selezionate. Memoria, spazio su disco e punteggio privacy non sono mostrati perché il repository non ha dati per questi.

### Altre impostazioni

Interruttori, pulsanti e l'elenco Multiplane Overlay si applicano subito, come in upstream. L'elenco DNS si applica con il pulsante Applica.
